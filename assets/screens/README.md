# Screenshots for aureum-dz.com

Drop the app screenshots here with exactly these names. Until a file exists, the
site shows a gold frame in its place — nothing breaks.

| File | Shown as | What to capture (phone, portrait) |
|---|---|---|
| `customer-home.webp` | Hero phone + tour "Home" | Customer home: overview, shop prices, For you |
| `discover.webp` | Tour "Discover" | Discover → budget search results (or the map tab) |
| `shop-page.webp` | Tour "Shop page" | A shop page with prices and pieces |
| `saved-vault.webp` | Tour "Saved and vault" | Saved pieces with a price-drop badge, or the vault |
| `nearby-pay.webp` | Tour "Buying at the counter" | Scan tab → nearby confirmation screen ("Same code") |
| `seller-dashboard.webp` | Tour "Shop dashboard" | Dashboard → Overview |
| `seller-sell.webp` | Tour "Selling" | Sell screen with a piece chosen |
| `widgets.webp` | Tour "Home-screen widgets" | Phone home screen with 2–3 Aureum widgets |

Tips:
- Take them in Arabic, on a shop with real-looking (but not private) data.
- Any size works; 1080 × 2340 is ideal. Convert to `.webp` (smaller) — or keep `.png`
  and change the file names in `index.html` to `.png`.
- Videos: put the links at the top of `index.html` in `window.SITE_VIDEOS`
  (`customer:` and `shop:`). The video block appears by itself once a link is there.
